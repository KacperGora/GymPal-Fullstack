## 🆕 Nowe odkrycia w audycie #3 (nie było w #1 i #2)

### 1. Walidacja haseł - naprawić dobrze

**Znalezienie:**
```typescript
// shared/src/schemas/auth.schema.ts
const passwordRegex = /^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)(?=.*[@$!%*?&])[A-Za-z\d@$!%*?&]{8,}$/;
```

**Co dobre:** ✅ 4 wymogi (upper/lower/digit/special), min 8 znaków
**Co mogłoby być lepsze:** Special chars ograniczone do `@$!%*?&` — rozważyć więcej

### 2. Prosty logging w main.ts (niekrytyczne)

```typescript
console.log('CORS origins:', corsOrigins);
```

**Status:** ✅ Zaledwie 1 log — lepiej niż się spodziewałem

### 3. Promise.all w wger.service — nie-N+1 czasami

```typescript
// exercises/wger.service.ts
const results = await Promise.all(
  ids.map(id => fetchExerciseById(id))
);
```

**Problem:** Jeśli `fetchExerciseById` to HTTP call, to rzeczywiście N+1
**Czy to problem?** Tylko jeśli lista jest duża (>100 ćwiczeń)
