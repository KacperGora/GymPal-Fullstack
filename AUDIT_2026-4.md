## 🔐 Security Deep Dive

### Account Lockout
```typescript
MAX_FAILED_LOGIN_ATTEMPTS = 5
LOCKOUT_DURATION_MINUTES = 15
✅ User.failedLoginAttempts counter
✅ User.lockedUntil DateTime field
✅ Auto-unlock after 15 min (verified on login attempt)
✅ Prevents brute force attacks
✅ Logged to Sentry for monitoring
```

### Password Policy
```regex
/^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)(?=.*[@$!%*?&])[A-Za-z\d@$!%*?&]{8,}$/
✅ 8+ characters
✅ Upper + lower + digit + special
✅ Enforced client + server
```

### JWT + Refresh Token Rotation
```
Access Token:   15 min (short-lived)
Refresh Token:  30 days (long-lived)
✅ Token family tracking (familyId)
✅ SHA256 hashing in DB
✅ Reuse detection → revoke whole family
✅ Device tracking (userAgent + IP)
```

### Sentry Integration
```
✅ Error tracking (5xx + exceptions)
✅ Performance monitoring (10% prod sampling)
✅ User context (JWT info)
✅ Correlation IDs (every request)
✅ Conditional send (ignores test env)
```

### CSP Headers
```
Production:
  defaultSrc: 'self'
  scriptSrc: 'self' (no inline)
  imgSrc: 'self' + data
  connectSrc: 'self' + api.wger.de
  frameSrc: 'none'

Development:
  unsafe-inline allowed (Swagger)
```

**Security: A- (no vulnerabilities)**
